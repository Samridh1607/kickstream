Security, privacy, and identity

Who can open the studio, and what is stored

Kickstream has two different fronts. On a developer machine the application has no sign-in of its own. On Azure, Container Apps authentication sits in front of the app and signs studio users in with Microsoft Entra ID.

Local machine

Anyone who can reach the pipeline can stream to the configured channels. The intended local deployment keeps the API and the web server on that machine. Stream keys live in .data/output-keys.json and are never sent back to a page. Guest pages are the exception: an HTTPS tunnel (Cloudflare Tunnel or ngrok) to port 5173 can expose them, because browsers allow cameras only on https:// or localhost. The tunnel hostname must be listed in KICKSTREAM_PUBLIC_HOSTS before start. On that hostname only guest routes, and a co-host’s studio routes, answer. If KICKSTREAM_PUBLIC_HOSTS is empty, the gate is off and a tunnel would open the whole studio.

Entra studio gate

deploy/terraform/auth.tf creates an application registration named “Kickstream studio” plus the resource name. sign_in_audience is AzureADMyOrg. The app requests Microsoft Graph User.Read only. A service principal requires app-role assignment. The deployer and every object id in studio_users receive the default access role. The redirect URI is https://<fqdn>/.auth/login/aad/callback.

Container Apps auth (Microsoft.App/containerApps/authConfigs, name current) enables the Azure Active Directory identity provider. Allowed principals are those same studio users. The app learns who signed in from the header named by KICKSTREAM_SIGNED_IN_HEADER, which the template sets to x-ms-client-principal-id. When public_view is true (the default), unauthenticated clients are allowed through and the app decides: /live and /match are read-only, and studio pages send everyone else to KICKSTREAM_SIGN_IN_URL, set to /.auth/login/aad. When public_view is false, unauthenticated clients are redirected to login. These paths stay open either way: /guest/*, /api/guest/*, and /assets/*.

This registration is a single-tenant gate for people who run the studio. Kickstream does not implement Microsoft Marketplace SaaS fulfillment, an Entra purchase landing page, or a live Partner Center offer.

Privileges inside the product

A co-host is not a limited director. From the studio they can go live, end or delete the broadcast, and create or revoke invites. Their “Join with camera” takes the host’s seat in the room. A speaker can be placed on stage and cannot open the studio. A member can join the call and cannot be placed on stage. While the broadcast is live, everyone backstage is muted.

Clubs and players in the synthetic match are fictional. Preferences such as a favourite club stay in the browser on the match page. The head-to-head record is only matches this installation has finished, not a licensed player database.
