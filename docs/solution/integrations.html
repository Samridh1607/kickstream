Integrations and data sources

Platforms, match feeds, speech, and models

Kickstream does not host the public video. It encodes one program and copies it to destinations the host already created. Match events come from a simulator, a detector file, or an optional feed. Models and speech are optional; templates and the browser voice cover the gaps.

Encode needs ffmpeg and a Chromium-based browser. KICKSTREAM_FFMPEG and KICKSTREAM_BROWSER override the paths. KICKSTREAM_PROGRAM_URL is the page the hidden browser opens (default the local studio output). Do not run the pipeline with --reload when going live: on Windows that mode cannot start ffmpeg.

Match sources

A deployment made with deploy/ offers the synthetic match only, unless real_sources = true. Locally the Match tool can also select the sources below. Live feeds carry key events (score, goals, cards, substitutions, and some team stats from API-Football) and no ball positions. Pitch, 3D pitch, replays, momentum, expected-goals graphs, next-action prediction, and the tactics chart then show “Not available with live data” instead of invented coordinates. The Tactical Analyst and the Visualization Agent sit out.

Speech, models, search, and comments

SystemWhen it is used
Azure AI SpeechAuto live’s captured voice. Key and region from the Speech resource (KICKSTREAM_SPEECH_KEY, KICKSTREAM_SPEECH_REGION). Daily character cap KICKSTREAM_SPEECH_DAILY_CHARS (default 200000). F0 allows 0.5 million characters a month; S0 is pay as you go. Repeated lines are cached. Without a key, or when Azure fails, the page uses the browser voice, which the stream does not hear.
Microsoft FoundryPreferred model path when KICKSTREAM_FOUNDRY_PROJECT_ENDPOINT and KICKSTREAM_FOUNDRY_DEPLOYMENT are both set. The app’s managed identity needs Azure AI User. Terraform assigns that role only if foundry_resource_id points at an existing resource.
OpenAI-compatible chatKICKSTREAM_LLM_BASE_URL, KICKSTREAM_LLM_MODEL, KICKSTREAM_LLM_API_KEY. Used when Foundry is not set. KICKSTREAM_LLM_MAX_CALLS defaults to 60 per match for narration.
Wikipedia or TavilyAsk Copilot web search, off until the host enables it. Wikipedia needs no key. Tavily needs KICKSTREAM_TAVILY_API_KEY. KICKSTREAM_WEB_SEARCH=off disables it. The Tavily adapter is tested against the documented response shape and has not been run against Tavily itself.
X APIOptional fan-zone source. KICKSTREAM_X_BEARER_TOKEN and KICKSTREAM_X_QUERY. Tested against the documented response shape, not against X itself. Other platforms use POST /api/fans/ingest.
MCP clientsAny client that speaks streamable HTTP can call POST /mcp. On a deployment that route is behind the studio sign-in.
Azure Communication ServicesGuest rooms. Locally, a connection string, or KICKSTREAM_ROOMS=fake for invites without audio or video between people.
